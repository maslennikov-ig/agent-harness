# Docs and Graphify

The documentation decision is a kernel rule and its resolver mechanics belong to
`docs-context`; load that skill instead of restating either here.

When the local graph has `graphify-out/GRAPH_REPORT.md`, Graphify is an optional
orientation aid. Read it and use focused `graphify query`, `path`, or `explain`
when it helps with unfamiliar architecture, relationships, or impact.
Never paste the full graph JSON into a prompt. Read-only audits query only.
Refresh after durable relevant changes at an accepted relevant integration/release
boundary when ownership is safe; otherwise record the bounded reason. External
semantic/model-backed extraction and Graphify git hooks need explicit
authorization.

For product UI, use Impeccable for craft and implementation. Lazyweb supplies
real-product evidence, experiments, screenshots, and hosted reports. Stitch is
explicit-only. Pair visually designed HTML-to-PDF with PDF rendering checks.
Design routing does not authorize delegation.

Record the exact documentation source and `graph-reviewed` outcome at closeout,
including `blocked` with the bounded reason when refresh is unsafe.
